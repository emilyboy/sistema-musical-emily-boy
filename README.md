🎵 Sistema Musical
Aplicação web desenvolvida para o gerenciamento de artistas e uma biblioteca musical completa. O sistema conta com interface responsiva, formulários estilizados, tabelas de listagem com opções de filtros e integração com conteúdos multimídia (como links do YouTube).

🚀 Tecnologias Utilizadas
Este projeto foi construído utilizando tecnologias essenciais de desenvolvimento web frontend:

HTML5: Estruturação semântica de todas as telas (Login, Menu Principal, Cadastro de Artistas, Cadastro de Músicas e Listagem).

CSS3: Estilização global customizada utilizando variáveis, Flexbox, CSS Grid para layouts em grade responsivos e adaptação para dispositivos móveis (media queries).

⚙️ Funcionalidades do Sistema
Tela de Login: Autenticação simulada com suporte a credenciais de teste.

Menu Principal: Painel central de navegação rápida para os módulos do sistema.

Gerenciamento de Artistas:

Cadastro de novos artistas informando nome, gênero musical, país de origem e envio de foto.

Tabela interativa com listagem, opções de edição, exclusão e atalho rápido para as músicas do artista.

Cadastro de Músicas:

Associação de músicas a artistas cadastrados.

Inclusão de dados como título, álbum, gênero musical, link direto para o YouTube, capa do álbum e letra da música.

Biblioteca Musical:

Listagem geral de músicas cadastradas.

Sistema de filtros por busca geral, artista específico e gênero musical.

Links diretos para assistir aos vídeos na plataforma do YouTube.

📂 Estrutura de Arquivos
O projeto está organizado com arquivos HTML individuais para cada tela e uma folha de estilos centralizada:

index.html — Menu principal do sistema

login.html — Tela de autenticação / login

cadastro_artista.html — Tela de cadastro e listagem de artistas

cadastro_musica.html — Tela de cadastro de músicas

listagem_musicas.html — Tela de biblioteca musical com filtros

styles.css — Folha de estilos unificada (layout, grid, botões e responsividade)
